Se espera que demuestres tu competencia en las siguientes áreas clave:

* Validación de Hipótesis (T-Test): Compararás dos conjuntos de datos independientes. Deberás calcular el p-value e interpretar si existe una diferencia significativa entre ellos basándote en un nivel de confianza del 95% (p < 0.05).
* Modelado de Regresión Lineal: Utilizarás la función linregress para encontrar la relación entre dos variables numéricas. Deberás obtener la pendiente y la intersección del modelo.
* Visualización y Predicción: Graficarás la "línea de mejor ajuste" sobre el diagrama de dispersión de los datos originales. Finalmente, usarás la ecuación obtenida para realizar una predicción de un valor que no se encuentre en el dataset original.
