# Proyecto: Introducción al Análisis Estadístico
> El objetivo de este proyecto es aplicar los conocimientos adquiridos durante el módulo en curso en los fundamentos estadísticos, basados íntegramente en el material expuesto en la sesión y las lecturas correspondientes. 

Se espera que demuestres tu competencia en las siguientes áreas clave:

* Exploración y Carga: Identificar la fuente de datos (en nuestro caso, los datasets integrados de Seaborn).
* Análisis Descriptivo: Resumir las características principales. ¿Cuál es el promedio? ¿Hay mucha variabilidad? ¿Cómo se distribuyen los datos?
* Visualización Exploratoria: Detectar patrones visuales y correlaciones iniciales.
* Aprendizaje Estadístico: Aplicar modelos (como la Regresión Lineal) para entender las relaciones y realizar predicciones.
