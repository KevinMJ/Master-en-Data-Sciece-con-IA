# Proyecto Challenge: Limpieza de Datos

## Objetivo
El objetivo de este challenge es aplicar los conocimientos adquiridos dentro del tema limpieza de datos, basados íntegramente en el material expuesto en la sesión y las lecturas correspondientes. 

## Competencias

Se espera que demuestres tu competencia en las siguientes áreas clave:

* Identificación y Tratamiento de Valores Nulos por Tipo de Dato: Diferenciar el tratamiento adecuado entre columnas de texto y columnas numéricas, aplicando la estrategia de imputación más coherente para cada caso.
* Estandarización y Conversión de Tipos de Datos: Normalizar columnas categóricas eliminando inconsistencias de texto y convirtiendo cada columna al tipo de dato que mejor representa su naturaleza dentro del dataset.
* Imputación Basada en Distribución Estadística: Analizar visualmente la distribución de las variables numéricas para justificar y aplicar la medida de tendencia central correcta en la imputación de valores faltantes.
