# Challenge: Herramientas de Análisis de Datos
> El objetivo de este challenge es aplicar los conocimientos adquiridos dentro del tema herramientas de análisis de datos, basados íntegramente en el material expuesto en la sesión y las lecturas correspondientes. 
Se espera que demuestres tu competencia en las siguientes áreas clave:

* **Generación de Indicadores**: Crea una nueva columna que calcule el porcentaje de proporción de probabilidad entre la propina y el total de la cuenta.

* **Segmentación de Datos**: Utiliza filtros condicionales para separar los datos por género para comparativa de estadísticas, de día de la semana y por tipo de cliente (fumador/no fumador) para análisis visuales.

* **Visualización con Seaborn**: Personaliza los gráficos a través de las dimensiones y los colores del gráfico para una mejor visualización. Utiliza Matplotlib.pyplot para asignarle características al gráfico.
