# Proyecto: Exploración de Datos

## Objetivo
El objetivo de este challenge es aplicar los conocimientos adquiridos dentro del tema exploración de datos, basados íntegramente en el material expuesto en la sesión y las lecturas correspondientes. 

## Competencias
Se espera que demuestres tu competencia en las siguientes áreas clave:

* **Detección y Tratamiento de Valores Atípicos:** Aplicar el método del Rango Intercuartílico (IQR) para identificar y filtrar outliers de manera estadísticamente fundamentada, evaluando la proporción de registros conservados tras el proceso.
* **Identificación de Relaciones entre Variables:** Generar e interpretar una matriz de correlación y correlaciones divididas por categoría para determinar qué pares de variables presentan una relación lineal significativa dentro del dataset.
* **Comunicación de Hallazgos a través de Narrativa Visual:** Construir visualizaciones orientadas a la audiencia que transmitan los principales patrones del dataset, utilizando gráficos de dona, barras horizontales con etiquetas y comparaciones por categoría.
