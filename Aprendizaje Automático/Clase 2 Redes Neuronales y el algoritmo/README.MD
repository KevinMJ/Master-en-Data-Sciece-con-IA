# Proyecto: Herramientas para el Aprendizaje Automático

> El objetivo de este challenge es aplicar los conocimientos adquiridos dentro del tema herramientas para el aprendizaje automático, basados íntegramente en el material expuesto en la sesión y las lecturas correspondientes. 
 
## Competencias 
Se espera que demuestres tu competencia en las siguientes áreas clave:

* Red Neuronal para Regresión: Implementar una red neuronal sencilla con TensorFlow/Keras para aprender la relación entre dos conjuntos de datos numéricos, visualizar la curva de pérdida durante el entrenamiento y guardar el modelo entrenado.

* Pipeline Completo de KNN: Aplicar el pipeline completo de Machine Learning supervisado: separar características y etiquetas, dividir en conjuntos de entrenamiento y prueba, normalizar los datos, entrenar un clasificador KNN y evaluarlo con un reporte de clasificación y matriz de confusión.

* Selección del Hiperparámetro K: Implementar el análisis de error para distintos valores de k y visualizar los resultados para identificar el valor óptimo que minimiza el error en el conjunto de prueba.
