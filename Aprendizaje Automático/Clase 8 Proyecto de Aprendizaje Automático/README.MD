# Proyecto Introducción al Aprendizaje Automático
> El objetivo de este proyecto es aplicar los conocimientos adquiridos durante el módulo en curso en la introducción al aprendizaje automático, basados íntegramente en el material expuesto en las sesiones y las lecturas correspondientes. 

## Competencias
Se espera que demuestres tu competencia en las siguientes áreas clave:

* **Análisis de Mercado:** Realizar un análisis exploratorio completo del dataset de vehículos eléctricos, identificando tendencias históricas, patrones geográficos o por segmento, y la evolución del mercado a través de visualizaciones narrativas.
* **Limpieza y Preparación de Datos:** Aplicar el pipeline de saneamiento de datos aprendido durante el Master, garantizando la integridad del dataset antes de cualquier análisis o modelado.
* **Aprendizaje Automático:** Implementar al menos un modelo de Machine Learning (supervisado o no supervisado) para extraer insights adicionales del mercado de vehículos eléctricos o realizar predicciones sobre su crecimiento futuro.
* **Recomendaciones Estratégicas:** Con base en el análisis y los modelos aplicados, proporcionar recomendaciones fundamentadas en datos para empresas que busquen ingresar o expandirse en el mercado de vehículos eléctricos.
