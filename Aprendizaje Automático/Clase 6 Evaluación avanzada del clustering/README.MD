
# Proyecto Aprendizaje No Supervisado
> El objetivo de este challenge es aplicar los conocimientos adquiridos dentro del tema aprendizaje no supervisado, basados íntegramente en el material expuesto en la sesión y las lecturas correspondientes. 

## Competencias
Se espera que demuestres tu competencia en las siguientes áreas clave:

* Clustering con K-Means: Entrenar un modelo de K-Means sobre el dataset creditcard.csv, separando correctamente la columna objetivo Class del resto de las columnas para el entrenamiento.
* Selección del K Óptimo: Identificar el mejor número de clusters utilizando conjuntamente el método del codo (inercia) y el método de las siluetas (Silhouette score), justificando la elección con ambas visualizaciones
* Etiquetado y Análisis: Añadir una columna cluster al conjunto de prueba (30% de los datos) con la asignación de cada registro al cluster predicho, e identificar en qué cluster o clusters se concentran los datos cuya columna Class es igual a 1 (transacciones fraudulentas).
