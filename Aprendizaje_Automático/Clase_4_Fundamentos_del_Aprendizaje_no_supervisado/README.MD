
# Proyecto Aprendizaje Supervisado
> El objetivo de este challenge es aplicar los conocimientos adquiridos dentro del tema aprendizaje supervisado, basados íntegramente en el material expuesto en la sesión y las lecturas correspondientes. 
 
## Competencias
Se espera que demuestres tu competencia en las siguientes áreas clave:

* Clasificación con KNN en Datos Médicos: Aplicar el algoritmo KNN al dataset de cáncer (data.csv) para detectar tumores malignos y benignos, evaluando el rendimiento del modelo con métricas apropiadas para el contexto médico (precisión, recall, F1-score y matriz de confusión).
* Clasificación Multiclase: Aplicar KNN al dataset de calidad del vino (Wine Quality Data) para una tarea de clasificación con múltiples categorías, evaluando la capacidad del modelo para distinguir entre distintos niveles de calidad.
* Evaluación del Rendimiento del Modelo: Interpretar los resultados de las métricas de evaluación y justificar la calidad del modelo en función del problema de negocio que resuelve.
